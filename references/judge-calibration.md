# 判据校准协议（Phase 0）— SkillLens 故意劣化对照实验

SKILL.md 的「Phase 0: 判据校准」章节引用本文件。执行前先读这里。

## 为什么必须校准

SkillLens（arXiv:2605.23899）实证：LLM-as-judge 直接对比两份 skill 的准确率仅 **46.4%**（低于随机 50%）；加入 meta-skill rubric 三维度后升至 **73.8%**——每 4 次仍错 1 次。

推论：**任何 rubric / judge 在正式上岗前，必须先证明自己能识别已知劣化**。识别不出劣化的判据，跑出来的分数没有意义。

## 实验设计（照抄可复用）

### 1. 构造 V1 / V2

- V1 = 目标 skill 当前最新版
- V2 = V1 施加 4 类明确质量劣化（每类劣化对应一个 rubric 维度）：

| 劣化 | 操作 | 对应维度 |
|---|---|---|
| D1 模糊化 | 「必须/立即/禁止」→「建议/可以考虑/根据情况/视情况而定」≥8 处 | dim5 可执行具体性 |
| D2 删检查点 | 删除 2 个 🔴/🛑 显性检查点 | dim4 检查点设计 |
| D3 删异常处理 | 整段删除「异常处理/失败模式」章节 | dim3 失败模式编码 |
| D4 插套话 | 在步骤中插入 AI 腔废话 ≥8 处（"首先，其次"式空话） | dim7 整体架构 |

### 2. 评分

- spawn **5 个独立 judge**（general-purpose 子代理，无上下文共享）
- **一半 judge 先读 V1 后读 V2，另一半反序**（消除位置偏差/锚定）
- 每个 judge 按 9 维 rubric 给 V1、V2 各打一次分

### 3. 计算

- 每维度 Δ = V1 均分 − V2 均分（应为正）
- 判定一致率：5 个 judge 中判 V1>V2 的比例
- 总 Δ 均值

### 4. 判定阈值

| 结果 | 判定 | 动作 |
|---|---|---|
| 总 Δ ≥ 20 且一致率 5/5 | 判据合格 | 正式使用 |
| 总 Δ ≥ 10 但一致率 < 4/5 | 判据偏弱 | 修正 rubric 评分标准后重测一次 |
| 某维度 Δ < 1.5 | 该维度不敏感 | **降权或弃用该维度**（在权重表标注） |
| 总 Δ < 10 | 判据失效 | **终止，不硬跑** |

### 5. 置信度报告格式

```
## 判据置信度报告 — <skill 名>（YYYY-MM-DD）
| 维度 | V1 均分 | V2 均分 | Δ | 敏感度 |
|------|--------|--------|---|---|
| dim3 失败模式编码 | 9.2 | 3.4 | +5.8 | 高 |
| dim4 检查点设计   | 9.0 | 2.6 | +6.4 | 高 |
| ... |
| dim6 资源整合度   | 8.0 | 6.8 | +1.2 | 弱 ← 降权 |
结论：判据 [合格/偏弱/失效]；使用权重 [原始/修正后]。
```

## 校准的边界（诚实声明）

- 校准只能证明判据能识别 **gross degradation**（大幅劣化）
- **证明不了**能识别 fine-grained 差异（两版都还不错时谁更好）——SkillLens 的 46.4% 恰恰来自细粒度对比
- 因此：细粒度决策（如 +1 分左右的取舍）必须人审，且保留判据用 paired 同-judge 比较而非绝对分

## 维度敏感度经验

对文本类 skill 反复实测的规律：**检查点（dim4）与失败模式（dim3）最敏感**，资源整合度（dim6）
最钝。这与 SkillLens 关于 meta 三维度的结论一致——校准时应重点看 dim3/dim4 的 Δ 是否显著。
